# Miyabi - Navidrome PWA Client

Navidrome用のPWA対応音楽プレイヤークライアントアプリケーションです。

## 特徴

- **PWA対応**: スマートフォンにインストールしてネイティブアプリのように使用できます
- **オフライン再生**: 楽曲を事前にダウンロードしてオフラインでも音楽を聴けます
- **モダンなUI**: Material-UIを使用した洗練されたユーザーインターフェース
- **完全なプレイヤー機能**: 再生/一時停止、シーク、音量調整、リピート、シャッフル対応

## 技術スタック

- **React 18** + **TypeScript**
- **Vite** - 高速なビルドツール
- **Material-UI (MUI)** - UIコンポーネントライブラリ
- **Dexie.js** - IndexedDB wrapper
- **Workbox** - Service Worker & PWA対応
- **Subsonic API** - Navidromeとの通信

## セットアップ

### 前提条件

- Node.js 18以上
- Navidromeサーバーが稼働していること

### インストール

```bash
npm install
```

### 開発サーバーの起動

```bash
npm run dev
```

ブラウザで `http://localhost:5173` を開きます。

### ビルド

```bash
npm run build
```

### プレビュー

```bash
npm run preview
```

## 使い方

1. アプリを開くと初回設定画面が表示されます
2. NavidromeサーバーのURL、ユーザー名、パスワードを入力します
3. 接続後、アルバム一覧が表示されます
4. アルバムをクリックして曲を表示し、再生できます
5. ダウンロードアイコンをタップしてオフライン保存できます
6. オフラインタブから保存した楽曲を確認・再生できます

## PWAとしてインストール

### モバイル (iOS/Android)

1. ブラウザでアプリを開く
2. ブラウザのメニューから「ホーム画面に追加」を選択
3. ホーム画面からアプリアイコンをタップして起動

### デスクトップ (Chrome/Edge)

1. アドレスバーのインストールアイコンをクリック
2. 「インストール」をクリック

## 注意事項

- Navidromeサーバーとの通信にはCORS設定が必要な場合があります
- オフライン保存時はブラウザのストレージ容量制限に注意してください
- パスワードはブラウザのLocalStorageに保存されます
